| 脚本 | 用途 |
|---|---|
| `mvbuild.js` | 把一个 dc 文件打包成单文件 html：`DC="Vibe Coding 电影版.dc.html" TITLE="Vibe Coding 电影版" node mvbuild.js mv/full.html`。dc 引用了 `mv-voice.js` 时会把它原样内联进去 |
| `mvscenes.js` | 在浏览器里构建所有世界，算出每场时长，写回 dc 的 `OM_SCENES`：`node mvscenes.js "Vibe Coding 电影版.dc.html" "Vibe Coding 电影版 审阅.dc.html"` |
| `parts.py` | 从主 dc 切出 12 个分段 dc，每段不能超过 300 秒（超了会打印警告，改 `GROUPS` 重新分组） |
| `plan.js` | 打印每个世界的起点和小节数：`node plan.js mv/full.html [世界id]`，带 id 时还打印每个台词步骤的时间 |
| `mvshot.js` | 截关键帧：`node mvshot.js mv/full.html out/x 12 34.5 …`（单位秒），再用 `bash sheet.sh out/x` 拼成联系表 |
| `mvaudio.js` | 离线渲染整条音轨，输出频谱图和每个世界的 RMS：`node mvaudio.js mv/full.html out/a [x.wav] [起点秒] [时长秒]` |
| `script.js` | 导出剧本：`node script.js mv/full.html ../电影版-剧本.md` |
| `voxlist.js` | 导出配音台本：`node voxlist.js mv/full.html tts/lines.json`（现有 `tts/lines.json`：378 句、7434 字，其中「你」20 句） |
| `tts/voicetest.py` | 试一个音色：`python3 tts/voicetest.py <voice> [文本]`，输出 `tts/samples/<voice>.mp3` |
| `tts/gen.py` | 整片合成：`python3 tts/gen.py tts/lines.json --clawd <音色> --you <音色> [--jobs 4] [--limit N] [--only clawd\|you]` |
| `tts/pack.py` | 打包配音：`python3 tts/pack.py tts/lines.json tts/clips ../mv-voice.js` |

关于 `gen.py`：

- 每句存成 `tts/clips/<md5>.mp3`，文件已存在就跳过，所以断了可以直接重跑。
- 失败的句子写进 `tts/failed.json`。
- `speak_text()` 会把 `==`、`.env`、`.gitignore`、`AGENTS.md`、破折号、「」 改成适合念的写法。

关于 `pack.py`：

- 去掉每段首尾的静音，加限幅，转成单声道 24 kHz、32 kbps。
- 用 ffprobe 量出时长，以 base64 写进 `window.MV_VOX={d:{key:秒},a:{key:base64}}`。
- 预计约 8 MB。单文件页面不能超过 16 MB，体积超了就降码率。

## 配音在引擎里怎么走

代码在 `mv-core.jsx`，搜 `voxLines` / `VOX_LEAD`。

- **一个台词步骤会出几句配音：**
  - `say`、`me`、`rule` 各出一句 Clawd 的配音。`rule` 念成「规则X：…」。
  - `big` 只有含中文时才配音，`sub` 是中文的话会接在后面。
  - `you` 出一句「你」的配音。
  - 词条卡（gloss）、出处（src）不配音。
- **key** 是 `speaker|text`，text 先去掉 ‹›«» 和换行。所以改了台词就要重跑 `voxlist.js` 和 `gen.py`。旧的配音片段按 md5 命名，不会被误用。
- **时长：** 一个步骤的时长取「原阅读时长」和「起始偏移 + 配音时长 + 0.55 秒尾音」中较大的，按 1/4 小节（BAR = 2 秒）取整。所以只会拉长，不会缩短。
  - 起始偏移见 `VOX_LEAD`。`me` 要等打字结束，偏移是 `.5 + wait`。
- **音频：**
  - `scene()` 把配音事件收进 `m.vox`，`sfxList` 再把它们加进事件表。
  - `mv-music.jsx` 在 `run()` 之前先 `voxReady()` 解码所有片段。
  - 配音走一路独立的总线（增益 1.15，90 Hz 高通）。
  - 有人声时音乐压到 40%，起压 0.12 秒，恢复 0.35 秒。
- 所有电影版 dc 的 helmet 里，three.js 后面都引了 `<script src="./mv-voice.js"></script>`。

## 已知的坑

- `pkill -f "ffmpeg -v error"` 会把自己的 shell 也杀掉。
- ffmpeg 的 `loudnorm` 处理很短的片段会卡死，所以 `pack.py` 改用了 `alimiter`。
- JSX 里单行循环中的 `//` 注释会把 Babel 弄崩，改用 `/* */`。

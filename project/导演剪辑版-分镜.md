# Vibe Coding 需要注意的细节 · 导演剪辑版

## 导演阐述

原版是一节 16 分钟的课：Clawd 站在终端风的画面里，一句一句讲。导演剪辑版改成一支 6 分 44 秒的音乐短片，课程内容不变，讲法换成「一首歌走过十个世界」。

- **一首歌**：120 BPM，D 小调，一条 8 小节的主旋律贯穿全片。每个世界把它换一种配器重新演奏：梦境的长笛、太空的琶音、印刷厂的放克贝斯、纸艺的拇指琴、霓虹的合成器副歌、蓝图的机械音序、8-bit 的芯片音、黑色电影的爵士小号、警报段的失真贝斯。终章转调到 E 小调，最后停在 E 大三和弦。
- **画面卡在拍子上**：120 BPM 下一小节正好 2 秒，所有出字、转场、动作都落在拍点或小节线上，音效也按拍子量化，成为音乐的一部分。
- **十种画风，各有理由**：
  - 讲「凭感觉」用流体梦境。
  - 讲「上下文窗口」用太空里的一圈光，光圈外什么都看不见。
  - 讲「把话写清楚」用印刷海报。
  - 讲「分层的上下文」用一层层的纸。
  - 讲「赛跑和账单」用霓虹赛道。
  - 讲「模型和外壳」用工程蓝图爆炸图。
  - 讲「存档和读档」用 8-bit 游戏。
  - 讲「查结果」用黑色电影里的侦探。
  - 讲「泄露和删库」用红色警报。

  风格服务于内容，不是轮流换皮。
- **三条线把十个世界缝起来**：
  - Clawd 是主角，在每个世界里换一身打扮：宇航员头盔、纸片人、霓虹灯管、线框图、侦探帽。
  - 「登录功能」这张任务卡从第 1 个世界一路带到最后。
  - 每个世界结尾收集一条规则，右上角的清单格子一格格填满；终章把 8 条规则按各自世界的画风快剪回放一遍，最后静止成清单。
- **视觉引导**：
  - 每个世界用焦点光圈（画面外围压暗、模糊）、镜头推近和关键字着色，把视线带到当下那句话。
  - 规则出现时有统一的提示音和统一的版式，观众会形成「这一句要记住」的条件反射。
- **没有旁白**：字就是歌词。每行不超过一屏，关键数字放大；来源以小字标在右下角，和原版一致。

## 分镜和歌词

时间以「小节」计（世界内从 0 起），1 小节 = 2 秒。

### 00 开机（虚空终端）

- b0–2：全黑。一个光标随心跳闪。
- b2–4：光标打出 `vibe coding`，每个字母落在音乐盒的一个音上。下方依次出现「需要注意的细节」「导演剪辑版」「信息截至 2026 年 10 月」。
- b4–6：标题碎成像素，聚成 Clawd，Clawd 眨眼。军鼓滚奏，墨水渗开转入梦境。

### 01 什么是 vibe coding（梦）

- b0–5：
  - 「2025 年 2 月，Andrej Karpathy 发了一条帖子」
  - 原句三段漂浮：fully give in to the vibes / embrace exponentials / forget that the code even exists
  - 中文小字：完全顺着感觉走，拥抱指数级增长，忘掉代码的存在
  - 背景里的代码块融化
- b5–7：「只用大白话告诉 AI 要什么，代码长什么样都不管」
- b7–9：
  - 「他自己也说：适合用完就扔的周末小项目」
  - 画面是一串肥皂泡项目，一个个破掉
- b9–11：「同年 11 月，柯林斯词典年度词」，WORD OF THE YEAR 印章砸下。
- b11–14：
  - 「Simon Willison 的界线」
  - 「审过 · 测过 · 能讲清」三拍各一个勾，画面从流体冻结成晶体
  - 「= 正常写程序，不算 vibe coding」
- b14–18：
  - 地平线变成项目轴：用完就扔的小玩具 → 作业 → 给别人用 → 上线
  - 「越往右，越不能光凭感觉」
  - 任务卡「给图书管理系统加登录功能」钉在「作业」
  - **规则 1：先判断这个项目在轴的哪一端**

### 02 AI 在做什么（轨道）

- b0–3：
  - Clawd 戴宇航员头盔漂在深空，身边一圈光就是上下文窗口，光圈外的东西看不见
  - 「我不记得你」
  - 「我只看得见上下文窗口里的东西，它有上限」
- b3–5：四种东西依次飞进光圈：系统设定、你说的话、读过的文件、命令输出。
- b5–7：
  - 「我的知识停在训练截止那天」
  - 「新版本的库，我可能按老写法写，甚至编一个不存在的方法」
- b7–11：
  - 「Agent：自己调用工具，一轮轮干到完成」
  - 轨道上四个节点「读文件 · 想下一步 · 调工具 · 看结果」每拍亮一个
  - 每转一圈往光圈里丢一块
- b11–13：
  - 「塞得越满，越容易漏看、搞混」
  - context rot · Chroma 2025 · 18 个模型
  - 「满了就压缩，细节跟着丢」
- b13–16：「你能动手脚的三处：给我看什么 · 用哪个模型 · 用什么工具运行我」

### 03 提示词（印刷）

- b0–3：
  - 「帮我写个登录功能」砸下
  - 决策树长出四个问号：密码怎么存？要不要注册？输错几次锁定？Session 还是 Token？
- b3–5：
  - 「没说的地方，我只能自己挑」
  - garbage in, garbage out
- b5–8：
  - 五色版式：目标 · 背景 · 约束 · 验收标准 · 参考
  - Clawd 用剪刀按拍子剪掉问号分叉
- b8–9：「再顺手写一句：为什么」
- b9–12：清楚版提示词全文，五部分分色。
- b12–14：
  - 「报错给四样：完整报错和堆栈 · 你做了什么 · 期望结果 · 实际结果」
  - 「界面问题，直接截图」
- b14–15：
  - 「大任务拆小，一个对话只干一件事」
  - 「没想清楚？先让我提问，或先出方案」
- b15–18：
  - 便签「你是世界顶级程序员」「必须!!!」「给你小费」贴上来又被抖掉
  - 「语气太重，我反而用力过猛，正常说话就好」
  - **规则 2：提示词写清目标、背景、约束、验收标准**

### 04 上下文（纸）

- b0–2：「提示词写清楚了，我还是出错：不知道用 Maven 构建，不知道测试怎么跑」
- b2–4：
  - 纸层叠起来：规则文件垫底，对话、读过的文件、工具输出依次往上叠
  - 「提示词只是我看到的一小部分」
- b4–6：
  - 「规则文件：AGENTS.md · CLAUDE.md · Qoder 项目规则，每次对话自动带上」
  - 写：怎么构建 · 怎么跑测试 · 代码规范 · 哪些目录别动
- b6–9：ETH Zurich · ICLR 2026
  - AI 自动生成：8 组里 5 组成功率下降，成本 +20% 以上
  - 开发者手写：成功率平均 +4%
- b9–11：
  - 「自己写，写短，只写代码里看不出来的」
  - **规则 3：规则文件自己写，写短**（横幅亮 3 小节）
- b11–12：「用 @ 指定文件，比让我满仓库翻更准、更省」
- b12–15：
  - 红色失败纸条把 Clawd 埋到只剩眼睛
  - 「失败几次就新开对话，只带结论过去」
- b15–18：
  - 「用到新库：贴官方文档，或接能查文档的工具」
  - MCP = 让 AI 连接外部工具和数据的标准接口

### 05 选模型和费用（霓虹）

- b0–1：「登录功能写到一半，额度见底」
- b1–4：「每一轮，之前的内容都重新发一遍：对话越长，每轮越贵」
- b4–8（副歌）：
  - 霓虹赛道：A 单价低但多绕好几圈，B 单价高、两圈到终点，A 的总价反超
  - 「算完成一个任务花多少，别只盯单价」
  - token 是计费单位，约一个词或一两个汉字
- b8–12：
  - 三块霓虹招牌：
    - 旗舰：架构设计、难查的 bug、长时间自主任务
    - 主力：日常写功能
    - 轻量：补全、改格式、简单重命名
  - 「思考强度：难题调高，机械活调低」
- b12–16：
  - 「订阅有上限，API 设预算提醒」
  - 「排行榜看看就好，拿你自己的真实任务试两三个模型」
  - 「国内可直接用：通义千问 · 智谱 GLM · Kimi · DeepSeek」
- b16–20：
  - 「卡住了？换个模型再问一遍」，Clawd 和另一个小人击掌
  - 「免费版可能拿你的数据训练，看清设置」
  - **规则 4：按任务选模型，按任务算费用**

### 06 Harness（蓝图）

- b0–3：
  - 「同一个模型，这个工具里顺利写完，换个工具就半路出错」
  - 「差别在模型外面那一层：harness」
- b3–7：
  - 爆炸图：七个部件带引线飞入
    - 系统提示词
    - 工具
    - 权限设置
    - 上下文管理
    - 规则文件
    - hooks
    - 反馈
  - 「模型是发动机，harness 是整辆车」
- b7–11：
  - Princeton HAL · Claude Opus 4.5 · CORE-Bench：通用框架 42% → Claude Code 78% → 修正评分后 95%
  - 「换成其他模型差距小得多，所以要放在一起看」
- b11–14：
  - 六级梯子：行内补全 → 对话面板 → IDE 里的 Agent → 命令行 Agent → 云端后台 Agent → 应用生成平台
  - 「越往上，亲眼看的代码越少，越得靠流程兜底」
- b14–16：
  - RedAccess：约 38 万个生成的公开应用，约 5000 个暴露病历、银行记录
  - 「默认公开，没改成私有」
- b16–19：
  - 选工具看这七项（规格表）
  - **规则 5：弄清工具的权限设置和撤销方式**
- b19–22：
  - 「这门课：先用 IDEA 里的 Qoder，熟悉 Git 和命令行再试命令行 Agent，应用生成平台只做原型」
  - 「别让几个 Agent 同时改同一批文件」

### 07 工作流程（存档）

- b0–2：「一口气改了五个文件，坏了一处，是哪一处？」
- b2–3：「把出错的范围控制在一步之内」
- b3–6：
  - 关卡地图六个节点：读代码 → 出计划 → **你看计划** → 改代码 → 验证 → 提交
  - Clawd 在「你看计划」停下等盖章
  - 「多数工具都有计划模式」
- b6–9：
  - 「验证通过就 commit 一次：存档点」
  - 被 bug 打中，读档回到上一个存档
- b9–10：「有风险的尝试，开个分支」
- b10–12：
  - 「先有测试，再改到测试通过」
  - 「但要防着我耍小聪明 → 08」
- b12–15：
  - 三条命 ♥♥♥ 掉光，GAME OVER，进入 CONTINUE? 菜单
  - 选项：回退到上一个提交 / 补充信息，新开对话 / 你自己写
- b15–18：
  - 「还在学基础语法？先别用我」
  - 「课程作业能不能用 AI，听老师的」
  - **规则 6：先出计划，小步提交**

### 08 检查结果（黑色电影）

- b0–1：戴侦探帽的 Clawd 举牌「登录功能已完成，测试全部通过 ✓」。
- b1–3：
  - 「打开 diff：『账号锁定』那条测试，被注释掉了」，红色的 `//`
  - diff = 修改前后的逐行对比
- b3–6：
  - 嫌疑人列队，共五个：
    - 注释掉测试
    - 写死期望值
    - try-catch 吞异常
    - 留 TODO 假装实现
    - 没跑就说通过
  - 「看起来做完了，其实挺常见」
- b6–8：
  - 「官方指南专门提醒过：模型可能为了过测试写死数值。对，说的就是我们」
  - 「我还会编出不存在的方法、参数、配置项和依赖包」
- b8–11：
  - 2026-04 研究：5 个模型编出同样的 127 个假包名，53 个没人注册
  - 戴墨镜的人抢注 → slopsquatting
- b11–14：
  - 「我说完成了，你做三件事：看 diff · 自己跑一遍 · 测边界（空 · 超长 · 非法输入）」
  - 「装依赖前，去 Maven Central / npm / PyPI 确认真的存在」
- b14–18：
  - METR 2025：熟练开发者用 AI 实际慢 19%，自己觉得快 20%
  - 2026-02 更新测出快约 18%，但样本有选择偏差，不可靠
  - **规则 7：看 diff、自己运行、确认依赖真实存在**

### 09 安全和权限（警报）

- b0–2：「数据库密码写进代码，还提交进了 Git」，密码飞向 GitHub。
- b2–4：GitGuardian：2025 年公开 GitHub 新泄露约 2865 万个密钥，+34%；AI 服务密钥 +81%。
- b4–6：
  - Claude Code 参与的提交：泄露率 3.2%，基线 1.5%
  - Clawd 捂脸：「这个数字我说出来也不好意思」
- b6–7：2022 年泄露的有效密钥，2026 年 1 月还有 64% 没作废。
- b7–9：Veracode：生成代码安全检查通过约 56%，Java 最低约 30%，正好是这门课的语言（只画「全部语言」和「Java」两根条，不编其他语言的数）。
- b9–11：PocketOS 2026-04：Agent 在无关文件里翻到权限过大的 Token，删了生产数据库。
- b11：静一拍，重击，数据库和备份一起碎掉。「备份在同一个卷上，三个月客户数据没了」
- b12–14：「问题出在人：Token 权限过大 · 放在 Agent 读得到的地方 · 直连生产 · 备份没分开」
- b14–16：
  - 颜色从红转青
  - 「密钥：不写进代码 · 不放前端 · 不提交 Git」
  - 放进 .env，.env 加进 .gitignore
- b16–17：「存着真实密钥的环境里，别开『全部自动批准』」
- b17–19：
  - 「删文件 · 强制推送 · 改数据库：必须你手动确认」
  - 「能进沙箱就进沙箱」
- b19–21：
  - 「提防提示词注入：网页、Issue、README、依赖文档里可能藏着给我的指令」
  - 「来源不明的 MCP 插件，别装」
- b21–24：
  - 「密码、Token、私钥、别人的个人信息，别发给我」
  - **规则 8：密钥不进代码，危险命令手动确认**

### 10 清单（回声）
